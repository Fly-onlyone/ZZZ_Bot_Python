# Frontend / pages — Map of Content

> Top-level route components. Most are lazy-loaded by [[PermanentDrawer Router]].
> Tools page hosts a tab container with nested Logs, Backup, Monitoring, LocatorTracker.

- [[Overview Page]] — landing dashboard with Mission + CompactRunningStatus
- [[Shopping Page]] — shopping list editor with DataGrid + hunt tab
- [[Redeem Page]] — redemption codes table
- [[Manual Login Page]] — start/stop browser login UI
- [[Locator Tracker Page]] — telemetry table with screenshot thumbnails
- [[Backup Page]] — selective export/import for SQLite tables
- [[Settings Page]] — multi-tab settings via ValueAdapter
- [[Account Page]] — account info, password, announcements tabs
- [[Tools Page]] — tab container for nested tools
- [[Monitoring Page]] — Sentry tracing sample rate selector
- [[Logs Page]] — application logs viewer with pagination

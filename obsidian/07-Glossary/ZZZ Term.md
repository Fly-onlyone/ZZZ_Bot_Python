# ZZZ

> Zenless Zone Zero — the HoYoverse action RPG whose HoYoLab events and rewards this bot automates.

## How it works
ZZZ is the target game. The bot does not interact with the game client itself; it only automates the web-side activities (daily check-in, event shops, code redemption, prize draws) hosted on [[HoYoLab]]. Avatar identification in the [[Image Recognition Pipeline]] uses ZZZ's character art to distinguish ZZZ events from other HoYoverse games sharing the same portal.
